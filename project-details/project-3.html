HIMSTOP Event Interface

Antarmuka informasi dan pendaftaran untuk event tahunan HIMSTOP dari HIMTI BINUS University.

Tentang project

Proyek ini merancang antarmuka platform untuk pendaftaran dan informasi event tahunan HIMSTOP yang diselenggarakan oleh Himpunan Mahasiswa Teknik Informatika (HIMTI) BINUS University. Tujuannya adalah menempatkan informasi acara dan alur partisipasi dalam satu pengalaman digital.

Konsep dan fitur utama

Rancangan platform mencakup kebutuhan informasi dan partisipasi peserta:

  • Jadwal seminar dan workshop.
  • Pendaftaran tiket peserta secara online.
  • Informasi pembicara utama.
  • Integrasi pembayaran QRIS dalam alur pendaftaran.
